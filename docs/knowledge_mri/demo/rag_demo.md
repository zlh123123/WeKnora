# RAG 学习演示材料

本文为本课题编写的简短演示材料，按本仓库代码许可证提供。它用于快速试跑，与正式审核所用教材快照分开。

## 检索增强生成

检索增强生成（RAG）先从外部知识库检索与问题有关的材料，再把材料和问题一起交给语言模型生成回答。它可以利用不在模型参数中的新资料。RAG 不要求为了每次文档更新都重新训练语言模型。检索不到答案时，系统应说明依据不足，而不是补造事实。

## 文本分块

文本分块把长文档拆成适合检索的较小片段。尽量沿标题、段落或句子边界切分，可以保留局部语义。分块太短可能丢失定义的上下文，太长可能混入无关主题。相邻片段的重叠可减少边界处的信息损失，但会增加重复内容。

## 嵌入模型

嵌入模型把文本转为数值向量。语义相近的文本通常在合适的向量空间中更接近。检索时分别编码问题和文档片段，再计算相似度。嵌入模型负责表示文本，生成模型负责组织最终回答，两者作用不同。

## 结果重排

结果重排对初步召回的候选再次评分和排序。初检索侧重快速找出可能相关的内容，重排侧重更细致地比较候选与当前问题。重排不能保证候选包含答案；如果初检索漏掉了关键材料，需要先改进召回。

## 来源与学习证据

回答展示来源，只能说明系统使用或展示了相关材料，不能证明用户看懂了。知识点验证题需要围绕核心定义、用途或区别提问。只记住环境名称不代表理解 RAG。答对两道题属于有限的验证证据，不能代替全面考试。
